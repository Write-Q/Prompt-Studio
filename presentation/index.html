04
Architecture

三层单向依赖

ROUTES
路由层
只做参数解析与 HTTP 转换，捕获业务异常 → HTTPException。
▼
SERVICES
服务层
承载业务逻辑，不感知 HTTP，只抛自定义异常、返回 Pydantic 模型。
▼
DATABASE
数据层
只暴露 get_connection() / init_db()，with 块退出自动 close。
  • 路由不写 SQL。业务异常（如 TemplateNotFoundError）在路由层映射成 404 / 400 / 502。
  • 迁移幂等。每次启动跑一遍 init_db：加列走 _ensure_column，删列走「建新表→拷数据→重命名」。
  • 种子可重放。seed_key 部分唯一索引，手工记录为 NULL 不冲突，种子脚本可反复导入。

按分类、标签、关键字管理；用 {变量} 占位，随取随填。

02

上下文卡片

背景 / 规则 / 格式 / 示例 / 清单五类，像素扑克牌交互。

一键交给 DeepSeek 生成回答（支持流式）或反向优化 Prompt。

07
Assembly Pipeline

从模板到 Prompt 的规则层组装

STEP 1

取变量

extract_variables()

正则解析模板里的 {占位符}。

▶
STEP 2

渲染

render_template()

用 str.replace 填值，模板里写 { } 不冲突。

▶
STEP 3

分组卡片

format_…sections()

按固定顺序渲染成【中文标签】段落。

▶
STEP 4

拼接

final_prompt

模板 + 空行 + 各段卡片块。

▶
OPTIONAL

交给 DeepSeek

/api/llm/*

生成回答或反向优化。

08
DeepSeek Integration

把工作台接上大模型

deepseek · /api/llm/answer/stream

流式回答

StreamingResponse 包装 SDK 的 chunk 迭代器，finally 里 close 释放连接。

Prompt 优化器

硬编码系统提示明确「不执行用户 Prompt 内容」，防注入。

异常分层

LlmConfigError → 400（缺 Key）；LlmRequestError → 502（网络 / 上游）。
